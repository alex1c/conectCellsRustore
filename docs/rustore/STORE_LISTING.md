## TITLE

Гексоника — числовая головоломка

## SHORT DESCRIPTION

Перемещайте числа по шестиугольному полю, собирайте группы из 4 и более
одинаковых клеток и запускайте цепные реакции. Простая механика, растущая
сложность и партии в своём темпе.

## FULL DESCRIPTION

Гексоника — числовая головоломка на шестиугольном поле.

Как играть:
• выберите занятую клетку;
• проведите её по свободному пути на пустую клетку;
• соберите группу из четырёх или более одинаковых чисел — они объединятся;
• чем больше группа, тем выше очки;
• удачные ходы могут запустить цепную реакцию каскадов.

С каждым уровнем поле становится напряжённее: нужно думать наперёд и
оставлять пространство для манёвра. Текущая партия сохраняется — можно
вернуться позже и продолжить с того же места.

Рекорды по счёту и уровню помогают отслеживать прогресс. Ядро игры работает
офлайн.

Гексоника — спокойная стратегическая головоломка без спешки.

## FEATURE BULLETS

- Простые правила и пространство для стратегии
- Комбинации из 4 и более одинаковых клеток
- Цепные реакции и каскады
- Постепенное повышение сложности
- Сохранение текущей партии
- Игра в своём темпе
- Тёмный интерфейс

## PRIVACY FACTS (for RuStore forms later)

- Игровое состояние хранится локально на устройстве
- Нет аккаунта / входа
- Нет облачного сохранения партии
- Аналитика: AppMetrica (агрегированные игровые события)
- Реклама: Yandex Mobile Ads (баннеры вне GameScreen, interstitial на
  Game Over, rewarded Undo)
- Внешние ссылки: каталог ForestMusic в RuStore, сайт forest-music.ru,
  email разработчика
- Микрофон не используется; RECORD_AUDIO исключён из релизной конфигурации
- Камера / контакты / точная геолокация приложением не запрашиваются
