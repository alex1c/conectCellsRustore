# Гексоника

Endless hex path-merge puzzle for Android / RuStore.

**Гексоника — числовая головоломка**  
Package id: `ru.forestmusic.connectcells` (unchanged).

## Scripts

```bash
npm install
npm run typecheck
npm run lint
npm test
# existing native dev client (always port 8082):
npx expo start --dev-client --port 8082
```

After native dependency changes (Ads / AppMetrica / SafeArea):

```bash
npx expo run:android
```
